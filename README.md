# Tubes_NLP

Proyek NLP klasifikasi pengaduan publik Indonesia. Dataset gabungan dan pembagian tugas dijelaskan di [panduan data](data/TASK_GUIDE.md).

- T1: klasifikasi domain dan intensi. Kode, cara menjalankan, dan keterbatasan evaluasi ada di [panduan T1](src/task1/README.md).
- T2: folder kerangka `src/task2/` untuk NER dan LDA.
- T3: sentimen dan sarkasme di `src/task3/`.
- Skema keluaran antar modul ada di `src/schema.py`.
